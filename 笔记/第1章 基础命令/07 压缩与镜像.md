## tar：打包与压缩

- **说明**：把多个文件打成 `.tar` 归档，或再用 gzip / bzip2 压缩；解压也用它。
- **语法**：`tar [-c -v -x -f -z -C] 参数1 参数2 … 参数N`
- **选项**
	- `-c`：压缩模式
	- `-x`：解压模式
	- `-v`：显示压缩 / 解压过程
	- `-f`：指定要创建或解压的文件，必须以 `.tar` 或 `.gz` 结尾
		- **位置**：必须放在所有组合选项的最后
	- `-z`：使用 gzip 格式（体积更小）；不加则为普通 tar（仅归档、不压缩）
		- 一般放在组合选项之首
	- `-j`：使用 bzip2 格式（压缩率更高、速度更慢），同样放在首位
	- `-C`：解压到指定目录；不写则在当前目录解压
- **参数**：要压缩的文件 / 文件夹，解压时不写

### 常用组合

1. **压缩**

```bash
tar -cvf  name.tar      file1 file2 …
tar -zcvf name.tar.gz   file1 file2 …
tar -jcvf name.tar.bz2  file1 file2 …
```

2. **解压**

```bash
tar -xvf  name.tar      -C target_dir
tar -zxvf name.tar.gz   -C target_dir
tar -jxvf name.tar.bz2  -C target_dir
```

## zip：压缩为 zip

- **说明**：压缩成 zip 包，跨平台友好。
- **语法**：`zip [-r] 参数1 参数2 … 参数N`
- **选项**
	- `-r`：递归处理子目录；要压缩的目录里有文件夹时必须加（与 `rm -r`、`cp -r` 同理）
- **参数**：要压缩的文件 / 文件夹

## unzip：解压 zip

- **说明**：解开 zip 包。
- **语法**：`unzip [-d 目标目录] 参数`
- **选项**
	- `-d`：指定解压到的目录
- **参数**：要解压的 zip 文件

## dd：按块复制

- **说明**：以“块”为单位复制并转换数据，常用于写镜像、制作启动盘。
- **语法**：`dd if=输入 of=输出 bs=块大小 count=块数 status=进度`

```bash
dd if=/dev/zero of=/tmp/test.img bs=1M count=100 status=progress
```

- **参数**
	- `if=`：输入文件，可以是普通文件，也可以是设备文件
		- `/dev/sda`：硬盘设备
		- `/dev/sdb`：U 盘设备
		- `/dev/zero`：无限输出 0 的设备
	- `of=`：输出文件；不存在则创建，已存在则覆盖
	- `bs=`：块大小，即一次搬多少字节
		- 可带单位 `K/k`、`M/m`、`G/g`、`T/t`
		- 大写按 1024 进制、小写按 1000 进制
	- `count=`：要搬多少块；不写则一直复制到输入结束
	- `status=`：进度显示
		- `none`：静默运行
		- `noxfer`：只给最终统计
		- `progress`：实时进度（默认）
