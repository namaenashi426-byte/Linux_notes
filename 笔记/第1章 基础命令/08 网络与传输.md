## ip命令

- **说明**：网络管理命令。

```bash
ip link        # 网卡状态、MTU、up/down
ip addr        # IP 地址
ip route       # 路由
ip neigh       # ARP/邻居表
ip tunnel      # 隧道
ip rule        # 策略路由
```

- `-br` 选项：简洁表格输出。

## curl命令

- **说明**：网络交互命令。

```bash
curl [options...] <URL>
```

- `-v` 选项：输出详细的通信过程，用于调试。
- `-L` 选项：自动跟随重定向，由于许多URL会发生301/302跳转，带上此选项后会自动跟随到最终地址。
- `-I` 选项：只获取响应头，适合轻量级网络访问检测。
- `-O` 选项：下载并保留原文件名。
- `-o` 选项：下载并在选项后指定文件名。

## wget命令

- **说明**：非交互式网络下载命令。

```bash
wget [选项]... [URL]...
```

- `-c` 选项：启用断点续传。

## time cmd／program命令

- **说明**：查看命令、程序运行耗时。

	输出由real（命令开始到结束的时间耗时）、user（用户态cpu时间）、sys（内核态cpu时间）三行内容组成。
