## ffmpeg：音视频处理

- **说明**：音视频格式转换、剪辑、抽帧的命令行工具。
- **语法**：`ffmpeg [全局选项] [输入选项] -i 输入文件 [输出选项] 输出文件`
- **规则**
	- `-i` 指定输入文件，`-i` **之前的非全局选项** 作用于 **输入**，**之后的选项** 作用于 **输出**
	- 输出格式由扩展名推断
- **术语**
	- 容器（container）：文件外壳，如 `.mp4`、`.mkv`、`.wav`，决定里面能装什么编码
	- 编码（codec）：音视频的压缩方式，如 H.264（`libx264`）、AAC、PCM
	- 关键帧：视频为了压缩，大部分帧只存 “和前一帧的差异”，不存完整画面。少数完整画面帧（I帧）被称为关键帧，关键帧可以独立解码，非关键帧必须依赖关键帧才能解码。
- **选项**
	**0.全局选项**
	- `-y`：若输出文件已存在，则直接覆盖
	**1. 编解码**  
	- `-c copy`：流复制，不重新编码，只换容器，==🔴输出容器须支持输入编码==（快速、无损）
	- `-c:v`：指定视频编码器（如`libx264`）
	- `-c:a`：指定音频编码器（如`aac`、`pcm_s16le`）
	**2. 质量控制**
	- `-crf`：一种“质量优先”的码率控制方式，不直接指定码率，而是指定目标画质。数值0～51，越小越清晰，常用范围 18(视觉无损) ~ 28(可接受)。==🔵`-crf` 与 `-b:v` 二选一==
	- `-b:v` / `-b:a`：指定视频 / 音频码率（如 `1M`、`128k`），控制视频帧 / 音频清晰度，数值越大最终输出的文件也越大
	**3.时间剪辑**
	- `-ss`：定位视频剪辑起点（如`00:01:30`或`90`）
		- 放 `-i` 前：**快速定位 + 重编码**，跳到离目标时间点最近的关键帧开始解码，并丢弃直到指定时间点前的解码帧，然后重新编码得到目标裁剪视频。==定位精准、速度稍快==
		- 放 `-i` 前 + 配合`-c copy` ：**快速定位 + 流复制（非重编码）**，跳到离目标时间点最近的关键帧开始流复制，不丢弃多余帧，最终得到目标裁剪视频。==定位不准、速度极快==
		- 放 `-i` 后：**解码后精准定位 + 重编码**，从头开始解码、并丢弃直到指定时间点前的解码帧，然后重新编码得到目标裁剪视频。==定位精准、速度最慢==
	- `-t`：指定视频剪辑持续时间，从起点往后持续多久（如`00:00:30`或`30`）
	- `-to`：指定视频剪辑直到哪个时间点结束（如`00:02:30`）。==🔵`-to` 与 `-t` 二选一==
	**4.滤镜相关**
	- `-vf`：视频滤镜
	    - `-vf scale=宽:高`：视频**帧缩放**，如`scale=1280:-2` 表示宽1280，高自动计算并保持偶数。
	    - `-vf crop=宽:高:x:y`：视频**帧裁剪**，如`crop=1280:720:0:0`表示裁剪出`1280×720`的区域，裁剪帧左上角原点坐标对应原帧的坐标`(0,0)`，==坐标参数决定具体裁剪行为==，坐标不指定时默认为“中央裁剪”（示意图如下）。
	     ![[中央裁剪示意图.png]]
	- `-af`：音频滤镜
	    - `-af volume=数值`：**音量调节**，如`volume=1.5`表示音量放大1.5倍
	**5.其他**
	- `-an` / `-vn`：去除音频 / 去除视频
	- `-frames:v N`：限制视频输出N帧；==🔵当 `N=1` 时相当于截图，可以配合`-ss`定位使用，截取对应时刻的一帧==
	- `-ar`：指定音频采样率（如 `44100`）
	- `-ac`：指定音频声道数，`1` 单声道、`2` 立体声
	- `-pix_fmt`：指定视频像素格式，`yuv420p`兼容性最好

### 应用示例

```bash
ffmpeg -i in.mp4 -c copy out.mkv                                  # 只换容器
ffmpeg -i in.mp4 -c:v libx264 -crf 23 -c:a aac -b:a 128k out.mp4  # 视频重编码
ffmpeg -i in.mp4 -vn -ac 2 -ar 44100 -c:a pcm_s16le out.wav       # 视频提取音频
ffmpeg -ss 00:01:30 -i in.mp4 -t 30 -c copy clip.mp4              # 视频粗剪（最快）
ffmpeg -ss 00:01:30 -i in.mp4 -t 30 -c:v libx264 -c:a aac c1.mp4  # 视频精剪（适中）
ffmpeg -i in.mp4 -ss 00:01:30 -t 30 -c:v libx264 -c:a aac c2.mp4  # 视频精剪（最慢）
ffmpeg -ss 1.5 -i in.mp4 -frames:v 1 shot.png                     # 视频截图
ffmpeg -i in.mp4 -vf scale=1280:-2 out.mp4                        # 视频缩放
```

> [!note] 注
 输入与输出不可同名，可以先写临时文件再 `mv` 重命名。
