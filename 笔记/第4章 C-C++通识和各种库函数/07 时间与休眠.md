## sleep

- **原型**：`sleep(unsigned int seconds)`
- **说明**：来自`<unistd.h>`，程序休眠指定秒数。

## nanosleep

- **原型**：`nanosleep(const struct timespec *req, const struct timespec *rem)`
- **说明**：来自`<time.h>`，使程序休眠，精度可达纳秒级。
- 参数1：指定**期望的休眠时长**，为struct timespec结构体指针。
- 参数2：保存**剩余未休眠的时间**（可实现**“断点续睡”**），为struct timespec结构体指针，用于在休眠被信号中断时（错误类型EINTR）。如果不需要此信息，可以传入NULL。
- 返回值：正确休眠指定时间后返回0，否则返回-1并设置全局变量errno`<errno.h>`来指示具体错误原因（可用perror()打印），错误类型主要有EINTR（被信号中断）、EINVAL（参数无效）等。
- **timespec**结构体：

```c
	  struct timespec{
     time_t tv_sec;        // 秒
     long long tv_nsec;    // 纳秒（范围0~999,999,999）
}
```

## clock_gettime

- **原型**：`clock_gettime(clk_id, struct timespec *tmp)`
- **说明**：来自`<time.h>`，获取当前时间戳。
- 参数1：**时钟类型**，可选CLOCK_MONOTONIC（**单调时钟**，不受系统时间调整影响）和CLOCK_REALTIME（**实时时钟**，与系统时间挂钩）。
- 参数2：**原始时间戳临时存储用结构体指针**，为struct timespec结构体指针。
- 返回值：正确休眠指定时间后返回0，否则返回-1并设置全局变量errno`<errno.h>`来指示具体错误原因（可用perror()打印）。
- 时间戳单位换算：此处ts即tmp指针。

```c
long long ns = (long long)ts.tv_sec * 1000000000LL + ts.tv_nsec;
long long us = (long long)ts.tv_sec * 1000000LL    + ts.tv_nsec / 1000;
long long ms = (long long)ts.tv_sec * 1000LL       + ts.tv_nsec / 1000000;
```

> [!tip] PS
> `tv_sec`使用LL强转是因为其为time_t类型，在某些32位设备上就是32位有符号整型，最大表达数值只到(2^32)/2=2.15e9。第一行算式中的tv_sec\*1e9中只要tv_sec\>2.15就必然会发生数值溢出（注意，此处指的是\*1e9的情形，而非图中的\*1e9LL，图中因为右操作数就是LL类型，所以即使去掉左操作数的强转也依然正确；图示做法可读性更好），因此，要先强转为64位的长长整型。
