## new

- **说明**：一个运算符，在“堆”上创建申请内存构造对象，并返回对象类型的指针。示例用法如 Ui \*p = new Ui。

## 字符串

- **说明**：可以使用“+”进行字符串拼接。

## 转换构造函数

- **说明**：一个只接受一个参数（或其余参数有默认值）且没有标记 为explicit 的类构造函数。当该类作为某个函数的类参数接收外部传来的不匹配的参数类型时将自动发生“隐式转换”触发转换构造函数，相当于“透过函数对该类构造函数传参以构造出一个该类的临时对象作为函数参数”。比如：

```c
	class A {
		public:
	  	  A(int x);          // 非 explicit，转换构造函数
		};
	class B {
		public:
	  	  explicit B(int x);   // explicit，非转换构造函数
		};
	void f1(A a);
	void f2(B b);
	f1(10);   // √隐式调用 A(10)，透过f1(A a)传int 10构造出A作为参数，相当于把 int 转成 A
f2(10);   // ×报错，int参数类型与B不匹配
```
