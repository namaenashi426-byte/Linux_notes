## fprintf

- **原型**：`fprintf(*stream,const char *format, ...)`
- **说明**：来自`<stdio.h>`，指定“输出流(\*stream)”的格式化打印函数，printf()的输出流固定为stdout，fprintf()的其余参数与printf()一致。常见输出流有：

	stdout：标准输出流。
	stderr：标准错误流。

## fopen

- **原型**：`fopen(file_path, const char *mode)`
- **说明**：来自`<stdio.h>`，参数1为文件路径，参数2为打开方式（"r"\\"w"等），返回值为FILE结构体指针`<stdio.h>`。发生错误时会返回NULL并写errno`<errno.h>`，常见错误有ENOENT（文件不存在）。
- **FILE结构体**：可视为一个文件操作对象，一般传指针**fp**。
- **fprintf(fp, const char \*format, ...)**：将字符串内容写入fp文件中。
- **fclose(fp)**：释放文件操作对象。
- **fgets(char \*line, int size, fp)**：从fp中读取一行字符到读缓冲区line，最大读size-1个字符（可直接传sizeof），成功返回所读字符串，失败或读完返回NULL。参数1为读缓冲区地址，参数2为长度变量地址（会自动分配和扩容，可初始化为0），参数3传fp。
- **getline(char\*\* lineptr, `size_t`\* len, fp)**：来自`<stdlib.h>`，从文件中读取一行内容（会读'\\n'）到读缓冲区line，返回实际读取字节数，失败或读完返回-1。参数1为读缓冲区指针地址，参数2为长度变量地址（会自动分配和扩容，可初始化为0），参数3传fp。==使用完毕后必须手动free释放读缓冲区line==。

## mkdir

- **原型**：`mkdir(const char *pathname, mode_t mode)`
- **说明**：来自`<sys/stat.h>`，系统编程中用于创建目录。参数1指定要创建的目录路径（字符串），参数2指定新目录的权限位，通常用八进制表示（如 0755）。
