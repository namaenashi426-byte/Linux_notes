## sizeof

- **原型**：`sizeof(type)`
- **说明**：不是函数，而是运算符，用于求某类型的字节数。无法正确计算指针型字符串的长度，届时应使用strlen(char\* str)\<string,h\>，如：

```bash
char *ptr = "hello";
char str[] = "hello";
sizeof(ptr)  >>  返回指针类型大小
sizeof(str)  >>  返回6（char字符数 + '\0'）
strlen(ptr)  >>  返回5（不包含 '\0'）
```

## strcmp

- **原型**：`strcmp(const char *s1, const char *s2)`
- **说明**：来自`<string.h>`，用于“字符串比较”。逐字节比较两个字符串，相等返回0。<mark>不能用“==”“!=”等直接进行</mark>==字符串比较==。

	- **strncmp**：`strncmp(const char *s1, const char *s2, size_t N)` —— 来自 `<string.h>`，用于“**字符串比较前N个字节**”，逐字节比较两个字符串，相等返回 0。

## strcpy

- **原型**：`strcpy(char *dest, const char *src)`
- **说明**：来自`<string.h>`，复制字符串，将参数2的字符串复制到参数1。==不检查目标缓冲区的大小（如果dest不够大，则会溢出）==。

## memcpy

- **原型**：`memcpy(void *dest, const void *src, size_t size)`
- **说明**：来自`<string.h>`，复制内存，将参数2的内容复制到参数1中，复制size（参数3）字节。可以用于“指定字符数的字符串复制”，但要注意：
- 若完全复制src内容，size必须为终止符‘\\0’预留位置。
- 若size小于src内容量，必须手动在dest末尾加上终止符‘\\0’。
- dest缓冲区大小必须大于等于size，否则会造成溢出。

## strchr

- **原型**：`strchr(const char *s, int c)`
- **说明**：来自`<string.h>`，在字符串中查找字符，返回指向查找到的首个匹配字符的字符串指针，找不到则返回NULL。

## strtok_r

- **原型**：`strtok_r(char *str, const char *delim, char **saveptr)`
- **说明**：来自`<string.h>`，按分隔符切分字符串。
- 参数1：**要切分的字符串指针，**==**必须指向可写内存（函数会改写该字符串）**==，首次调用时传递，此后若不需更换为新字符串，则只需传NULL。
- 参数2：**分隔符数组**，按匹配的分隔符进行切分，==注意，多分隔符连续出现时只视为单个分隔，故该函数“会跳过空字段”，可能会导致数据读取错位==。
- 参数3：**单次切分后的后续字符串的存储指针地址，**==**必须指向可写内存（函数会改写该字符串）**==，通常使用一个char\* ptr=NULL取地址即可。
- 返回值：每次调用返回当次切分的结果，当切分到不再有匹配的分隔符时返回NULL。

## memset

- **原型**：`memset(void *ptr, int num,size_t size)`
- **说明**：来自`<string.h>`，将ptr所指内存的size个字节全部置为num，可用于“结构体清零”。

## strcat

- **原型**：`strcat(char* dest, char* src)`
- **说明**：来自`<string.h>`，将src字符串拼接到dest末尾。参数1为目标字符串（==必须初始化为真实字符串如""，且为数组型并手动分配字节大小==），参数2为要拼接的字符串。
