## QApplication类

- **说明**：来自\<QApplication\>，管理 Qt 事件循环和全局资源，一个进程只能有一个。
- QApplication::**exec()：进入Qt 事件循环**，阻塞直到退出。

## QWidget类

- **说明**：来自\<QWidget\>，其为所有可视控件的基类，同时为顶层窗口。
- QWidget::**resize(W, H)：设置UI窗口大小**。
- QWidget::**show()：显示UI窗口**。
- `QWidget::setStyleSheet(const QString &styleSheet)`：进行界面美化和个性化定制的“控件”级实现，通过“样式表字符串”指定设计的样式，QWidget 的所有子类控件均可调用此方法。
- 样式表字符串基本格式：

```bash
"选择器 {
```

属性1: 值1**;**

属性2: 值2**;**

```bash
}"
```

当选择器省略时仅表示自指。属性和值有background-color(#)、font-size(px)、font-weight(px)、color(#)等。

## QPushButton类

- **说明**：来自\<QPushButton\>，按钮控件。
- 构造方法**QPushButton(const QString &text)：按键的初始显示文本**。一般使用new进行初始化构造并实例化为其的一个对象指针。
- QPushButton::**setText(QString &text)：更新按键文本**。
- QPushButton::**clicked**：按键信号，**按键按下并松开**。
