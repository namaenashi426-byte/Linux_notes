## QLabel类

- **说明**：来自\<QLabel\>，文本显示控件。
- 构造方法**QLabel(const QString &text)：Label的初始显示文本**（字符串参数会触发QString的转换构造函数自动转换为QString类型）。一般使用new进行初始化构造并实例化为其的一个对象指针。
- QLabel::**setText(QString &text)：更新Label文本**（字符串参数同上会先自动转为QString类型）。
- QLabel::**setAlignment(Qt::Alignment)：设置Label文本对齐方式**，对齐方式如下表所示。

| Qt::AlignLeft | 与左边缘对齐 |
| --- | --- |
| Qt::AlignRight | 与右边缘对齐 |
| Qt::AlignHCenter | 可用空间中水平居中 |
| Qt::AlignJustify | 可用空间内两端对齐 |
| Qt::AlignTop | 与顶部对齐 |
| Qt::AlignBottom | 与底部对齐 |
| Qt::AlignVCenter | 可用空间中垂直居中 |
| Qt::AlignBaseline | 与基线对齐 |
| Qt::AlignCenter | 水平、垂直居中对齐 |

## QString类

- **说明**：来自\<QString\>，Qt字符串类型。
- 构造方法**QString(const char\* str)：将string转为QString**。是一个参数为字符串类型的“转换构造函数”。
- QString::**number(int)：将整型转QString**。
- QString::**number(int, int base)：按 base 指定进制将整型QString**。
- QString::**number(double, char format, int precision)：将浮点型转QString**。format可指定'e'（科学记数法）、'f'（普通小数计数）、'g'（智能选择），precision进而指定“小数点后位数”、“小数点后位数”、“最大有效数字位数”。

## QStringList类

- **说明**：来自\<QStringList\>，Qt字符串列表类型，可以给函数传“参数列表”。
- 构造方法**QStringList(`string_list`)**：可传QString或QList\<QString\>，取决于要传的参数个数。
