## 简介

- **说明**：vi 是 visual interface 的简称，vim 是它的加强版，兼容 vi 的全部指令，并支持语法着色。

![[简介.png]]

## 工作模式

- **说明**：分为命令模式、编辑模式和末行模式。
- **启动**：若文件路径存在，直接打开；若不存在，则会自动创建。

![[工作模式.png]]

- **命令模式**：启动vi\\vim时自动进入。
	- 模式切换：
		按下**i\\a\\o\\I\\A\\O**均可切换为**编辑模式**，按**ESC或 Ctrl+\[** 将退回命令模式；
		按下“**：**”切换为**末行模式**，按**ESC或 Ctrl+\[** 将退回命令模式，回车执行命令后也会退回命令模式。
	- 按键功能：

| 按键 | 补充 | 实现功能 |
| --- | --- | --- |
| i | non | 直接插入：在光标当前位置插入编辑 |
| a | non | 追加插入：在光标下一个位置插入编辑 |
| o | non | 后行插入：在光标下一行插入编辑 |
| I | non | 行首插入：在光标所在行的开头插入编辑 |
| A | non | 行尾插入：在光标所在行的末尾插入编辑 |
| O | non | 前行插入：在光标上一行插入编辑 |
| H | ← | 光标左移 |
| J | ↓ | 光标下移 |
| K | ↑ | 光标上移 |
| L | → | 光标右移 |
| 0 | non | 光标移动至行首 |
| \$ | Shift + 4 | 光标移动至行尾 |
| gg | non | 光标移动至第一行的行首 |
| G | non | 光标移动至最后一行的行首 |
| PgUp | 小键盘顶 | 向上翻页 |
| PgDn | 小键盘顶 | 向下翻页 |
| / | R-Shift左 | 搜索模式：光标处往后搜索、匹配最近 |
| n | non | /:继续向后匹配搜索结果 |
| N | non | /:继续向前匹配搜索结果 |
| yy | non | 单行复制：复制当前光标所在行的内容 |
| nyy | n为数字 | 多行复制：复制当前光标及往后n行的内容 |
| p | non | 粘贴复制的内容（光标下一行） |
| u | non | 撤销上一个修改操作 |
| Ctrl + r | non | 反向撤销u命令 |
| x | non | 删除光标处字符 |
| D | non | 删除光标后所有本行字符 |
| dd | non | 单行删除：删除光标当前所在行的内容 |
| d0 | 组合cmd | 删除光标当前位置直至行首的内容 |
| d\$ | 组合cmd | 删除光标当前位置直至行尾的内容 |
| ndd | n为数字 | 多行删除：删除当前光标及往后n行的内容 |
| dgg | 组合cmd | 删除当前行直至第一行的内容 |
| dG | 组合cmd | 删除当前行直至最后一行的内容 |

- **编辑模式**：顾名思义，进行文本编辑的主要模式。其只能由命令模式进入，也只会退回命令模式。
- **末行模式**：用来执行一些诸如内容保存、退出vi\\vim等底层命令。

| 命令 | 实现功能 | 补充 |
| --- | --- | --- |
| :w | 仅保存 |  |
| :q | 仅退出 | 修改未保存时退出失败，退回命令模式并返回提示 |
| :q! | 强制退出 | 不返回提示直接退出 |
| :wq | 保存并退出 | 最常用命令 |
| :行号n | 光标跳到第n行 |  |
| :set nu | 显示行号 | :set number |
| :set nonu | 不显示行号 | :set nonumber |
| :set paste | 进入粘贴模式 | 此时在编辑模式中粘贴内容将不改变原始格式 |
| :set nopaste | 退出粘贴模式 |  |
| :%s/p1/p2/g | 字符替换 | 将p1全局替换为p2 |
