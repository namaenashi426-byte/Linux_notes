## pthread_join

- **原型**：`pthread_join(pthread_t thread, void **retval)`
- **说明**：等待指定线程结束，参数1传线程句柄（直接传），参数2接收线程返回值（不关心则传NULL）。==程序执行完毕后必须执行，否则线程资源不会回收==。

## pthread_mutex_t

- **说明**：互斥锁，是一个控制多个线程中谁获得唯一执行权的线程变量。可在线程函数中用pthread_mutex_lock(`pthread_mutex_t` \*mutex)“加锁”和用pthread_mutex_unlock(`pthread_mutex_t` \*mutex)“解锁”。

	lock和unlock间的代码称为“临界区”，同一时刻只能有单个线程即持锁线程进入，可有效防止对全局变量操作时的数据竞争。但加锁有一定程度的性能开销，应当避免短时间内频繁加解锁，且临界区内代码应尽量短、不要有打印等IO操作。==加锁后一定要有解锁，且临界区内不应有return语句，否则会造成“死锁”，导致其他线程拿不到锁==。
	互斥锁有两种初始化方式：
- 静态互斥锁：使用`PTHREAD_MUTEX_INITIALIZER`初始化，生命周期与程序一致，无须手动消耗。如果锁是用于保护整个程序生命周期内的全局资源，且数量固定、无需特殊属性，静态方式是最简单、最高效的选择。
- 动态互斥锁：使用函数 `pthread_mutex_init(pthread_mutex_t *mutex, const pthread_attr_t *attr)` 初始化（==线程create前==），使用 `pthread_mutex_destroy(pthread_mutex_t *mutex)` 销毁（==须先join线程==）。当**需要在程序运行时根据需要创建和销毁锁**，或者需要设置特殊属性（如**递归锁**或**跨进程共享锁**）时，必须使用动态初始化。

## pthread_cond_t

- **说明**：条件变量，可在线程函数中使用，是一个描述“线程结束休眠、继续执行的条件（含开始工作条件和线程结束条件两种含义）”的线程变量，使用方式如下：
- **条件等待**：等待其他线程函数发送唤醒信号。语句通常包装在while内而不是if内，防止被虚假唤醒。

```c
while(!ready) {
		pthread_cond_wait(pthread_cond_t *cond, pthread_mutex_t *mutex);
}
```

其中，while里的ready才是真正意义上的“**条件变量/条件谓词**”，该标志位被置1会退出循环，即结束等待。编写代码时，可以考虑“线程在**什么条件下**进入等待”，将其值或其取反值作为循环条件变量。比如此处，当数据没有准备好（ready=0）时线程进入等待，故将其取反值作为循环条件变量。

==条件标志位必须在锁内读写==（这会确保拿到锁后才修改，因为等待方也是在拿到锁后才休眠，如果不拿锁就修改，可能会出现唤醒信号发送时等待方还没开始休眠的情形，进而导致丢唤醒而陷入永久睡眠；拿锁后再广播可以切实解决丢唤醒问题，但等待方一般还会在锁内轮询条件标志位，于是等待方的持锁读和修改方的非持锁写又可能导致出现数据竞争的未定义行为；即使等待方的条件轮询放在锁外，两方线程对同一标志位非持锁的读和写依然可能产生数据竞争，而避免这个问题正是互斥锁的存在意义）。

更进一步，==**线程函数对其与外部共享的变量的读写都必须在锁内读写，防止数据竞争**==。

条件等待函数会释放锁，并令当前线程休眠，直到接收到“唤醒信号”后返回，并拿回被释放的锁。
- **唤醒信号**：由其他线程函数发送以结束当前线程、函数的条件等待。唤醒信号可以在锁外发送。
	- **pthread_cond_signal**：`pthread_cond_signal(pthread_cond_t *cond)` —— 会唤醒至少一个正在等待该条件变量的线程。要保证修改了正确的“条件标志位”，才能确保它能够唤醒到正确的线程。
	- **pthread_cond_broadcast**：`pthread_cond_broadcast(pthread_cond_t *cond)` —— 唤醒所有等待该条件变量的线程。
		条件变量也有两种初始化方式：
- 静态条件变量：使用`PTHREAD_COND_INITIALIZER`，其余与静态互斥锁一致。
- 动态条件变量：使用函数 `pthread_cond_init(pthread_cond_t *cond, const pthread_attr_t *attr)` 初始化（==线程create前==），使用 `pthread_cond_destroy(pthread_cond_t *cond)` 销毁（==须先join线程==），其余与动态互斥锁一致。
