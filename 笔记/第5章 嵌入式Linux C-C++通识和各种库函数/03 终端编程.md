## 库文件（termios.h）

- **说明**：`<termios.h>`。

## tty设备

- **说明**：泛指计算机“终端设备”，有
- 串口终端(ttyS\*)：代表串口设备。
- 伪终端(pts/\*或pty)：供用户使用。
- 控制终端(tty)：是一个特殊“别名”，即当前进程所关联的那个控制终端，无论实际使用的是哪个终端设备。在某些条件下（如会话首进程），打开一个终端设备会让它自动成为调用进程所在会话的控制终端。
- 虚拟控制台(tty1...)：由内核模拟的虚拟终端。
- 控制台(console)：系统的主控制台，常与第一个虚拟控制台（tty1）相关联，用于显示内核启动信息等系统级消息。

## termios结构体

- **说明**：来自`<termios.h>`，“终端属性结构体”，内含输入/输出波特率、控制标志（输入、输出、控制模式）等，是终端编程的基础。

> [!info] 函数命名规律
> `tc` → 终端控制（terminal control）；`cf` → 控制标志（control flag）

- **典型配置流程**
	- [[#tcgetattr]]：先把当前属性读进 `struct termios`
	- 修改结构体字段：控制标志见 [[#控制字符标志位（c_cflag）配置]]，波特率见 [[#cfsetspeed]]
	- 只想原样收发数据时，可直接用 [[#cfmakeraw]] 切到原始模式
	- [[#tcsetattr]]：把改好的配置应用到终端，才真正生效

## tcgetattr

- **原型**：`int tcgetattr(int fd, struct termios *termios_p)`
- **说明**：读取 `fd` 终端当前的属性，写进 `termios_p` 指向的结构体 —— 相当于给 `struct termios` 做一次初始化。
- **参数1**：`int fd` —— 已打开的串口/终端文件描述符。
- **参数2（传地址）**：`struct termios *termios_p` —— 用于接收当前属性的结构体。
- **返回值**：成功 `0`，失败返回 `-1` 并设置 `errno`。

## cfmakeraw

- **原型**：`void cfmakeraw(struct termios *termios_p)`
- **说明**：把 `termios_p` 配置成“原始模式”：关闭行缓冲/规范模式、关闭回显、关闭特殊字符处理、关闭输入输出字符转换、关闭软件流控。
- **参数（传地址）**：`struct termios *termios_p` —— 待修改的结构体。
- **返回值**：无返回值（`void`），改完还要调 `tcsetattr` 才生效。
- **适用场景**：串口会尽量把收到的数据原样交给程序，适合二进制协议、自定义帧协议等。改完通常还要自己设置波特率（见 [[#cfsetspeed]]）与数据位/校验位（见 [[#控制字符标志位（c_cflag）配置]]）。

## 控制字符标志位（c_cflag）配置

- **说明**：`termios` 的 `c_cflag` 字段负责“数据位 / 校验位 / 停止位 / 硬件流控”，`c_cc` 数组负责 `read()` 的读取行为。
- **配置代码**：

```c
/* 配置串口终端使用本地连接、启用数据接收 */
tty.c_cflag |= (CLOCAL | CREAD);

/* 配置串口终端使用 8N1：8 数据位、无校验、1 停止位 */
tty.c_cflag &= ~CSIZE;          // 清数据位
tty.c_cflag |= CS8;             // 设 8 数据位
tty.c_cflag &= ~PARENB;         // 不使用奇偶校验
tty.c_cflag &= ~CSTOPB;         // 清 2 停止位标志，即使用 1 停止位
tty.c_cflag &= ~CRTSCTS;        // 关闭硬件流控

/* 配置读取行为，控制 read() 的行为 */
tty.c_cc[VMIN] = 1;             // 至少读到 1 字节才返回
tty.c_cc[VTIME] = 0;            // 不设置读取超时
```

- `CLOCAL`：忽略调制解调器控制线，本地连接。
- `CREAD`：启用数据接收。
- `CS8`：8 个数据位；设置前先用 `&= ~CSIZE` 清掉原来的位数。
- `~PARENB`：不做奇偶校验；`~CSTOPB`：使用 1 个停止位。
- **`VMIN` / `VTIME`**：`VMIN` 是最少读到的字节数，`VTIME` 是读取超时。

> [!tip] PS
> 读取超时 1 代表 100ms，10 即为 1s。

## cfsetspeed

- **原型**：`int cfsetspeed(struct termios *termios_p, speed_t speed)`
- **说明**：同时设置输入、输出波特率。
- **参数1（传地址）**：`struct termios *termios_p` —— 待修改的结构体。
- **参数2**：`speed_t speed` —— 波特率宏，如 `B9600`、`B115200`。
- **返回值**：成功 `0`，失败返回 `-1` 并设置 `errno`。
- **注意**：只改了结构体，仍需 `tcsetattr` 才生效。

## tcsetattr

- **原型**：`int tcsetattr(int fd, int optional_actions, const struct termios *termios_p)`
- **说明**：把 `termios_p` 里配置好的属性应用到 `fd` 终端 —— 相当于“配置落盘”，前面对结构体的修改到这一步才真正生效。
- **参数1**：`int fd` —— 已打开的终端/串口描述符。
- **参数2**：生效时机
	- `TCSANOW`：立即生效
	- `TCSADRAIN`：等输出队列排空后生效
	- `TCSAFLUSH`：等输出排空并清空输入队列后生效
- **参数3（传地址）**：`const struct termios *termios_p` —— 配置好的结构体。
- **返回值**：成功 `0`，失败返回 `-1` 并设置 `errno`。
