## 库文件（fcntl.h、unistd.h）

- **说明**：`<fcntl.h>`和`<unistd.h>`。

## open

- **原型**：`open(char* dev_file, int o_flag)`
- **说明**：来自`<fcntl.h>`，打开设备文件并返回fd。参数1指定设备文件路径"/dev/..."，参数2指定打开方式如O_WRONLY（只写）、`O_RDONLY`（只读）、`O_RDWR`（读写）。针对串口，常用按位或（|）在o_flag处同时配置O_NOCTTY防止其转换为控制终端。

## read

- **原型**：`read(fd,char* buf, size_t n_bytes)`
- **说明**：来自`<unistd.h>`，从fd读入n_bytes个字节放到buf缓冲区。正常将返回实际读入的字节数，出错时将返回-1并配置errno`<errno.h>`，如遇到EINTR可按需求重试。

## write

- **原型**：`write(fd,char* buf, size_t n_bytes)`
- **说明**：来自`<unistd.h>`，从buf写入n_bytes个字节到fd，返回实际写入的字节数。

## close

- **原型**：`close(fd)`
- **说明**：来自`<unistd.h>`，释放fd。

## lseek

- **原型**：`lseek(fd, offset, whence)`
- **说明**：来自`<unistd.h>`，设置已打开文件的读写偏移量（file offset）。即在文件中移动一个“读写光标”，后续的read或write操作将从光标的新位置开始。
- 参数1：文件描述符。
- 参数2：相对于基准位置的偏移量（offerset）。
- 参数3：基准位置。使用宏定义：`SEEK_SET`（文件开头），`SEEK_CUR`（当前位置），`SEEK_END`（文件末尾）。
- 返回值：成功返回新文件偏移量（从文件开头算起的字节数），失败返回-1并写errno`<errno.h>`。
