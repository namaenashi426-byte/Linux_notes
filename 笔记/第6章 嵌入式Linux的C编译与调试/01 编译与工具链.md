## main：入口参数

- **原型**：`int main(int argc, char **argv)`
- **参数解析**
	- **`argc`**：参数个数（按空格分割）。如 `./hello HanMo` → `argc = 2`
	- **`argv`**：参数字符串数组，`argv[0]` 是程序名、`argv[1]` 起是参数。如 `argv[1] = "HanMo"`

## gcc：编译 C 源码

- **说明**：把 `.c` 文件编译成可执行程序。
- **语法**：`gcc [-o 输出文件名] 要编译的.c文件`
- **选项**
	- `-o`：output，指定输出的可执行文件名
	- `-pthread`：代码里用到线程时加
	- `-lm`：用到 `<math.h>` 时加，链接数学库

## 运行编译产物

- **说明**：按 `command [-options] [parameter]` 的形式运行，如 `./hello HanMo`。
- **省略 `./`**：把产物所在目录加入 `PATH` 后，可以直接用名称运行。

## export：设置环境变量

- **语法**：`export 变量名=值`
- **示例**：`export PATH=$PATH:/home/UserName/Code`
	- `$PATH` 展开当前值
	- `:` 是路径分隔符
	- 对 `PATH` 重新赋值即完成追加
- **生效范围**（按持久程度）
	1. **临时**：只在当前 shell 及其子进程有效，退出即失效
	2. **当前用户永久**：写入 `~/.bashrc`
		- 嵌入式板端若没有 `~/.bashrc`，可在 `etc/profile.d/` 下新建 `xxx.sh`，开机会自动加载
	3. **所有用户永久**：写入 `/etc/environment`
		- 该文件不能用 `export` 写入，只能手动编辑 `PATH` 行

## 交叉编译工具链

- **说明**：在 Ubuntu 主机上编译出能在 ARM 板子上运行的程序。普通 `gcc` 编译的产物架构不匹配，必须用板子配套 BSP 里的交叉工具链。
- **配置步骤**
	1. 把下面几行追加到 `~/.bashrc`
	2. 重载配置：`source ~/.bashrc`
	3. 用 `arm-buildroot-linux-gnueabihf-gcc -o output file.c` 编译

```bash
cat >> ~/.bashrc <<"EOF"
export ARCH=arm                                    # 目标硬件架构：ARM
export CROSS_COMPILE=arm-buildroot-linux-gnueabihf-  # 交叉编译器前缀
export PATH=$PATH:~/tool_chain_path/bin            # 工具链 bin 目录
EOF
```

- **注意**：直接改 `PATH` 会污染环境（交叉编译包与系统同名包冲突），更稳妥的做法是写成别名按需启用：

```bash
alias arm_env='export PATH=$PATH:~/tool_chain_path/bin'
```
