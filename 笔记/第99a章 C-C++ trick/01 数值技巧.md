## 环形下标修正

- **说明**：代码：num = (num + 1) % `out_num`

说明：`out_num`指数组、缓冲区队列等的最大容量，亦即首个越界下标值。
- 操作1：等同于num++。
- 操作2：操作1越界后，使num回归0。

## 取模与整除

- num % 10^n：**“去除十进制数高n位”**。
- num / 10^n：**“去除十进制数低n位”**。
	说明：需为“整型运算”或“计算结果强转为整型”。

## 生成“随机浮点数”

- **说明**：需要`<stdlib.h>`。

	代码：`rand_num` = `min_num` + (`max_num` - `min_num`) \* rand() / (double)`RAND_MAX`;
- **数值归一化**：Normal = (N - `N_Min`) / (`N_Max` - `N_Min`)，归一化范围\[0, 1\]。
- **线性映射**：x = min + (max - min) \* Normal，最终范围\[min, max\]。
	以上两步将原始（计数/软件）范围\[`N_Min`, `N_Max`\]映射到目标（实际/硬件）范围\[min, max\]。==除法注意转double再除防止计算结果舍入出错==。

## 将当前时间设为随机种子

- **说明**：需要`<time.h>`、`<stdlib.h>`。

	代码：srand( (unsigned) time(NULL) )
	说明：可以实现将程序运行时刻作为rand()的随机种子，直接把该语句视作在程序开头“设置随机种子”即可。
