- [[01 数据类型与修饰符]]
	- 数据类型
	- case：1e4：本质“浮点型常量”，在进行某些特定情形下的整型运算时，需注意隐式转换和数值舍入所带来的精度问题。
	- const修饰：一般用于“只读”变量。
	- static修饰：静态变量，该变量只在本文件内有效、可使栈对象生命周期持续到主程序结束。
	- enum枚举类型：可以用于实现“状态机”。
	- 逻辑非 '!'：逻辑取反。
	- extern ”C”

- [[04 字符串处理函数]]
	- sizeof：不是函数，而是运算符，用于求某类型的字节数。
	- strcmp：来自`<string.h>`，用于“字符串比较”。
	- strcpy：来自`<string.h>`，复制字符串，将参数2的字符串复制到参数1。
	- memcpy：来自`<string.h>`，复制内存，将参数2的内容复制到参数1中，复制size（参数3）字节。
	- strchr：来自`<string.h>`，在字符串中查找字符，返回指向查找到的首个匹配字符的字符串指针，…
	- strtok_r：来自`<string.h>`，按分隔符切分字符串。
	- memset：来自`<string.h>`，将ptr所指内存的size个字节全部置为num，可用于“结构体清零”。
	- strcat：来自`<string.h>`，将src字符串拼接到dest末尾。
- [[05 数值与格式转换]]

	- strtol：来自`<stdlib.h>`，将字符串转long int型，参数1传入需要转换的字符串；参数…
	- sscanf：来自`<stdio.h>`，扫描src字符串，按format指定格式化赋值给后续变量地址。
	- isxdigit：来自`<ctype.h>`，判断字符是否为16进制数（0\~f、F），返回非零值表示真。
- [[06 错误处理]]
	- strerror：来自`<string.h>`，将错误码errnum转为人类可读的字符串。
	- perror：来自`<stdio.h>`，将errno`<errno.h>`的对应错误描述输出到标准错误流…
- [[07 时间与休眠]]
	- sleep：来自`<unistd.h>`，程序休眠指定秒数。
	- nanosleep：来自`<time.h>`，使程序休眠，精度可达纳秒级。
	- clock_gettime：来自`<time.h>`，获取当前时间戳。

	- mkdir：来自`<sys/stat.h>`，系统编程中用于创建目录。
- [[09 C++ 特性]]
	- new：一个运算符，在“堆”上创建申请内存构造对象，并返回对象类型的指针。
	- 字符串：可以使用“+”进行字符串拼接。
	- 转换构造函数：一个只接受一个参数（或其余参数有默认值）且没有标记 为explicit 的类构造函数。
	- auto类型：自动推导类型，==必须初始化==。
